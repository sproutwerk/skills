## Sibling skills

- Stock Dalamud ImGui (bindings, `Window`, Dalamud's `ImRaii`, fonts, textures) → `dalamudimgui`.
- Dalamud services, plugin lifecycle, hooking rules, API migration → `dalamud`.
- ECommons (`Svc`, `ImGuiEx`, `EzConfig`, `TaskManager`), on which Artisan and AutoRetainer are
  actually built → `ecommons`.
- NightmareUI and `NightmareUI.OtterGuiWrapper` (`ConfigFileSystem`, `GenericFileSystem`) →
  `nightmareui`.
- Luna and ImSharp, OtterGui's successor → `luna` (Penumbra/Glamourer-style plugins only).
