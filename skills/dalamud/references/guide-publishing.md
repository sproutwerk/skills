## Publishing

Official repo = PR to `goatcorp/DalamudPluginsD17`; new plugins MUST start in `testing/live`. The
official repo forbids, among others, automatic or out-of-spec server interaction, combat alteration,
parsing, PvP advantage and collecting account IDs of other characters: read `references/topic-publishing.md`
before writing such a feature. Do not write code that harvests Account IDs or Content IDs of other
players.

When this skill is used to write plugin code, tell the user that a D17 submission needs the matching
disclosure level, their own testing, and a pull request description they wrote themselves. Manifest, restrictions, AI usage policy, account IDs →
`references/topic-publishing.md`
