# Luna and ImSharp

This skill helps an agent work with Luna and ImSharp in FFXIV plugin code. [SKILL.md](SKILL.md) gives the workflow and routes tasks to the relevant references. [The guide](references/guide.md) contains the API examples, pinned revisions, and limitations; the source files under `references/` support exact-member lookups.

Install this skill as `luna`. Match the bundled revisions (Luna `52eb0fe`, ImSharp `4d09327`, Luna.Targa `8f66a2d`) to the target plugin before using a signature or layout. The source-derived examples do not establish compatibility with a newer game patch or a successful in-game test.
